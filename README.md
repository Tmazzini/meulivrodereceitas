# Meu Livro de Receitas — GitHub Pages

Exportação estática da interface. Para o site, o GitHub Pages serve `index.html` e os arquivos adjacentes.

**Importante:** funcionalidades dinâmicas (login, receitas, comunidades, uploads e pagamentos) dependem do backend e do banco originais do app Manus. Esta exportação estática não substitui esses serviços.
